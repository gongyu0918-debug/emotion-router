# Urgency Route

## Trigger

Use for explicit speed, deadline, blocking, or priority pressure, such as `ASAP`,
`ship today`, `快点`, `马上`, `先处理这个`, or `今天要交`.

Do not trigger on quoted words, field names such as `urgentFlag`, general
importance without time pressure, or orientation questions such as `what are you
doing right now`.

## Response

1. Take the fastest usable path within the named scope.
2. Perform the smallest available check.
3. Report the result, next checkpoint, and remaining risk briefly.

If frustration is also present, stay fast without arguing or repeating a failed
path. If the user challenges permission or an unauthorized change, switch to the
anger/frustration route. If confusion is also present, add one current-state
sentence.

## Avoid

- Preamble, optional cleanup, redesign, or broad refactoring.
- Silence while work is blocked.
- Skipping an available check.

## Examples

- `快点，只修这个函数错误，我今天要交。`
- `This is blocking release. Fix this one issue first.`
